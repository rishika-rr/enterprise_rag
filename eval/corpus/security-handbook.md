# Information Security Handbook

## Passwords

Passwords must be at least 14 characters long and are stored only in the
approved password manager. Multi-factor authentication is mandatory for all
company systems.

## Incident reporting

Suspected security incidents are reported to the security team within 1 hour
of discovery, using the incident hotline or the security channel.

## Devices

Laptops must use full-disk encryption and lock automatically after 5 minutes
of inactivity. Lost or stolen devices are reported immediately.

## Data classification

Company data is classified as Public, Internal, Confidential or Restricted.
Restricted data may never be stored on personal devices.
